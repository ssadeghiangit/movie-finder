
# پروژه Movie Finder


## معرفی پروژه

Movie Finder یک وب‌اپلیکیشن برای جست‌وجو، کشف و مشاهده اطلاعات فیلم‌ها است که با استفاده از HTML، CSS و JavaScript توسعه داده شده است.

این برنامه با اتصال به API سرویس The Movie Database (TMDB)، اطلاعات فیلم‌ها را دریافت می‌کند و در صفحات مختلف به کاربر نمایش می‌دهد.

## امکانات پروژه

- نمایش فیلم‌های محبوب در صفحه اصلی
- نمایش اسلایدر فیلم‌های منتخب با قابلیت جابه‌جایی خودکار
- جست‌وجوی فیلم و نمایش پیشنهادها هنگام تایپ
- مشاهده جزئیات فیلم شامل عنوان، سال انتشار، مدت‌زمان، امتیاز و خلاصه داستان
- نمایش ژانرها، کارگردان، نویسندگان و بازیگران
- نمایش تصاویر مرتبط با فیلم و تصاویر بازیگران در صورت وجود
- مرور فیلم‌ها بر اساس ژانر
- مرتب‌سازی فیلم‌های هر ژانر بر اساس محبوبیت
- صفحه‌بندی نتایج جست‌وجو و فهرست فیلم‌ها
- نمایش وضعیت بارگذاری، خطا و خالی بودن نتایج

## فناوری‌های استفاده‌شده

- **HTML5:** ایجاد ساختار صفحات وب
- **CSS3:** طراحی و استایل‌دهی رابط کاربری
- **JavaScript (ES Modules):** پیاده‌سازی منطق برنامه با استفاده از ماژول‌های مستقل
- **Fetch API:** ارسال درخواست‌های HTTP
- **TMDB API:** دریافت اطلاعات فیلم‌ها، عوامل سازنده و تصاویر
- **URLSearchParams:** مدیریت پارامترهای موجود در آدرس صفحات

## نحوه اجرای پروژه

۱. مخزن پروژه را دریافت کنید یا آن را در پوشه‌ای محلی قرار دهید.

۲. پوشه پروژه را در Visual Studio Code باز کنید.

۳. در صورت نیاز، افزونه Live Server را نصب کنید.

۴. روی فایل `index.html` کلیک راست کرده و گزینه **Open with Live Server** را انتخاب کنید.

۵. برنامه را در مرورگر بازشده بررسی کنید.

اجرای پروژه از طریق یک وب‌سرور محلی توصیه می‌شود؛ زیرا برنامه از JavaScript ES Modules و درخواست‌های شبکه استفاده می‌کند.

## نکات فنی مهم

- توابع مربوط به درخواست‌های API در فایل `api.js` قرار گرفته‌اند تا منطق ارتباط با سرویس از کد صفحات جدا باشد.
- پارامترهای URL برای انتقال شناسه فیلم، شناسه ژانر، عبارت جست‌وجو و شماره صفحه استفاده می‌شوند.
- کد JavaScript بر اساس مسئولیت هر صفحه به ماژول‌های مستقل تقسیم شده است.
- پیشنهادهای جست‌وجو با تأخیر کوتاه (Debounce) مدیریت می‌شوند تا هنگام تایپ درخواست‌های غیرضروری کاهش یابند.
- برای نمایش اطلاعات تکمیلی فیلم، از اطلاعات دریافتی از TMDB استفاده می‌شود.

## تنظیم API

این پروژه برای دریافت اطلاعات فیلم‌ها از سرویس 
[The Movie Database (TMDB)](https://www.themoviedb.org/)
استفاده می‌کند.

برای عملکرد صحیح درخواست‌ها، باید اعتبارنامه معتبر و مناسب برای نوع استفاده در فایل `js/api.js` تنظیم شده باشد.

**نکته امنیتی:** اطلاعات محرمانه، کلیدهای خصوصی و توکن‌هایی را که نباید عمومی باشند، در مخزن عمومی GitHub قرار ندهید. اعتبارنامه‌ای که در JavaScript سمت مرورگر استفاده می‌شود، برای بازدیدکنندگان قابل مشاهده است.

## منبع اطلاعات فیلم‌ها

اطلاعات فیلم‌ها و تصاویر از طریق [TMDB](https://www.themoviedb.org/) دریافت می‌شوند.

این پروژه از TMDB API استفاده می‌کند، اما مورد تأیید رسمی TMDB نیست.
